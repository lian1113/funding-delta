怎麼看這個表？

  • 正數：Long 付錢給 Short → 適合在那個平台開 Short 收 Funding。
  • 負數：Short 付錢給 Long → 適合開 Long。
  • 做中性通常是：在 APR 最高的地方 Short，在 APR 較低的地方 Long 同樣標的。
注意：Funding 每小時變動。三個平台的深度、滑點、手續費都不同。高數字常常是暫時的。Ondo 因為 API 不支援瀏覽器直接呼叫，所以沒有放進去。
